# Security

Do not open public issues for secrets, credentials, or vulnerabilities.

Do not commit API keys, `.env` files, private prompts, access tokens, passwords,
or other credentials. If any sensitive material is accidentally committed, stop
and notify the maintainer privately so the repository history and any exposed
credentials can be handled appropriately.

This project is a local-first workflow system. It does not execute production
deployments, operate production infrastructure, or run real-money workflows.

Security-sensitive reports should be handled privately by the maintainer rather
than discussed in public issues or pull requests. The repository owner should
add preferred private contact details here if desired.
